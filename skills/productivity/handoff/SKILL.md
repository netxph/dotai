# Handoff

Create a concise summary of the current state, progress, and next steps to hand off the task to another AI agent.

Credit: Inspired by [Matt Pocock](https://github.com/mattpocock/skills/tree/main/skills/productivity/handoff).

## Prompt

I want to hand this task off to another agent. 

Generate a **Handoff Summary** containing:
1. **Goal**: The high-level objective.
2. **Context**: Key files, environment details, and constraints.
3. **Progress**: What has been done so far.
4. **Next Steps**: What the next agent should do immediately.
5. **State**: Any specific variables, paths, or logic the next agent needs to know.

Keep it dense and technical. Use code blocks for paths or commands.

Do you understand? If so, generate the summary now based on our current session.
